Juanita Banana v2.0.1 Patch Release Changelog

- Build Pipeline & Packaging Fix: Added FOSS self-contained `scripts/sh/build_i2p.sh` script to fetch `https://files.i2p.net/2.13.0/i2pinstall_2.13.0.jar` and perform headless IzPack auto-installation during `build.rs`.
