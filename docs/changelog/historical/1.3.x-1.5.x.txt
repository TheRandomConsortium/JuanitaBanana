Juanita Banana Historical Releases (v1.3.0 – v1.5.7)
===================================================

Version 1.5.7
-------------
- Migrated all println! and eprintln! calls in application source files to the structured log! macro with proper categories and levels.
- Implemented support for the JUANITA_LOG_OVERRIDE environment variable to allow per-system log level overrides.
- Updated documentation to list "Clever Heuristic for Toxicity" under planned features.

Version 1.5.6
-------------
- Refactored browsing modules to keep them organized.
- Cleaned up unused imports and dead code.

Version 1.5.5
-------------
- Refactored tab inactivity timeout checking into `tab_cleanup.rs` to keep `gui.rs` strictly under 500 lines.
- Added `in_destruction()` checks on notebook, entry, and button references to guard against double-free/use-after-free events during application shutdown.
- Prevented background timers from executing during application termination by returning `ControlFlow::Break` if the main window is in destruction.
- Refined Settings page `<select>` element styling with white background and black text to ensure visibility on all GTK themes.

Version 1.5.4
-------------
- Fixed middle-click on links not opening in a new tab by checking `nav_decision.mouse_button() == 2`.
- Fixed tab names getting cleared and loading/nuking infinitely when closed by inactivity by ignoring WebKit load events on killed tabs.
- Added notebook hover (enter-notify) and window focus-in triggers to seamlessly execute tab cleanup when user attention returns.
- Fixed Settings page dropdown visibility on dark mode by rendering options with black text on white background.

Version 1.5.3
-------------
- Added CleanupGuard to terminate local hnsd resolver daemon on application exit or panic.
- Enhanced hnsd daemon initialization to check process status via try_wait() and clean up failed handles to prevent port collisions.
- Refactored tab management and page removal/sync logic into a dedicated module tab_cleanup.rs to comply with the 500-line limit.
- Replaced basic tab headers with interactive EventBox + GtkBox widgets containing a close button 'x' and support for middle-click closing.
- Intercepted NewWindowAction policy decisions and added custom context menus to support "Open Link in New Tab" navigation.
- Shared a single RssNoiseProvider across all tabs to prevent redundant RSS crawler thread spawns.
- Fixed inactivity active_count tracking in the timer loop to prevent nuking the last active tab.
- Preserved tab label titles when tabs are killed by TTL to prevent layout shifting.

Version 1.5.2
-------------
- Fixed a RefCell mutably borrowed runtime panic that occurred when adding a new tab, caused by the switch-page signal firing while the tabs list RefCell was still mutably borrowed.

Version 1.5.1
-------------
- Added a new Warn log level weight (1) to the LogLevel enum and environment variable parser in debug utilities.
- Switched newly introduced and existing raw console outputs (println!) for domain banning in gui.rs and message_handler.rs to structured log! macro calls at the Warn level.
- Migrated HTML viewer disk-saving console feedback to log! calls under the Info and Error levels.

Version 1.5.0
-------------
- Added customizable tab settings to AppConfig, allowing configuration of tab inactivity TTL (1 to 60 minutes) and last tab nuke behavior (survive or redirect to home).
- Overhauled the browser UI layout by replacing the single WebView packing with a tabbed GtkNotebook widget, adding a dynamic new tab "+" button to the headerbar.
- Integrated background inactivity audit monitoring that automatically shuts down inactive webviews in the background, updating tab labels to "tab closed due to inactivity in 0 frames" to preserve user attention.
- Implemented deferred tab pruning: visually reordering and removing dead tabs occurs only when the notebook tab headers or url entry bar are focused by the user.
- Decoupled context menus and unsubscribe flows to query active tab contexts dynamically using ACTIVE_TAB thread-local storage, ensuring correct target isolation in multi-tab workspaces.
- Refactored gui.rs to extract all tab management code into its own submodule tab.rs, keeping gui.rs clean and under the 500-line budget limit.
- Updated the local RPM builder (build_rpm.sh) to support auto-incrementing build releases when executing builds with version bump argument set to none.

Version 1.4.0
-------------
- Added subliminal guilt trip overlay to remind the user about toxic browsing habits, featuring category-configurable high-fidelity meme overlays (Ceiling Cat for NSFW/porn, Donald Trump for news, Fry "Take My Money" for shopping/gambling, Wojak "Touch Grass" for social media/time wasting, and Banana for fallbacks).
- Overhauled webconsole log interception, capturing guest page console messages (`console.log`, `console.error`, etc.) inside the webview and routing them to the Rust log macro under the debug levels.
- Reconfigured GitHub CI compilation script for hnsd (recursive resolver) by adding libunbound-dev, autoconf, automake, and libtool dependencies to the Ubuntu runner image to resolve build panics.
- Corrected templates/config.html spaced template placeholder parsing error which previously caused page scripts to break on configuration updates.
- Restored Guilt Trip Overlay subliminal opacity limits (capped slider back to a maximum of 0.1).
- Avoided injecting ad-intoxication, fingerprint-spoofing, toxic warnings, or guilt overlays on internal local pages (juanita://*).

Version 1.3.5
-------------
- Refactored the monolithic `src/resolver/mod.rs` into a clean, modular submodule architecture under `src/resolver/` (`helpers.rs`, `system/`, and `hns/`).
- Implemented fully asynchronous resolver integration in GTK policy decision hooks using non-blocking channels and local GLib futures.
- Resolved browser GUI freezing/locking up during slow Handshake resolver network timeouts by offloading resolutions to spawned worker threads.
- Ensured seamless and responsive fallback capability to system DNS for unresolvable Handshake domains.

Version 1.3.4
-------------
- Implemented dynamic DNS resolution utilizing the user's configured priority chain (Handshake -> System).
- Eliminated static clearnet TLD checklists in favor of checking system DNS resolvability dynamically via `is_system_resolvable`.
- Resolved infinite redirect loops on clearweb sites (like google.com) by natively loading domains that are resolvable via the system DNS, bypassing IP-rewriting.
- Implemented robust host normalization (`clean_host`) to correctly parse URIs containing custom ports (e.g. :8080), userinfo (e.g. user:pass@), and IPv6 brackets (e.g. [2001:db8::1]).
- Integrated a thread-safe mapping registry (`RESOLVED_IPS`) to intercept GTK load-changed events and restore original domain names in the address bar.

Version 1.3.3
-------------
- Resolved a port collision conflict in the Handshake resolver system where both the root nameserver (ns) and the recursive nameserver (rns) components of the `hnsd` daemon attempted to bind to the same port (5349).
- Configured root nameserver to bind explicitly to port 5349 (`-n 127.0.0.1:5349`) and recursive nameserver to port 5350 (`-r 127.0.0.1:5350`).
- Implemented background log readers for `hnsd` daemon process's `stdout` and `stderr` streams.

Version 1.3.2
-------------
- Added a dedicated `handshake_enabled` configuration setting to allow enabling or disabling Handshake resolution independently from the BIOS resolver chain.
- Implemented a checkbox toggle for the Handshake daemon in the Resolver Stack tab of `juanita://config`.
- Configured the `hnsd` resolver daemon to be immediately shut down if Handshake is disabled during runtime.

Version 1.3.1
-------------
- Fixed compilation and linting checks by resolving cargo clippy warnings.
- Removed unused `LogLevel::Warn` variant and corresponding environment parser cases.
- Restored standard mapping for the custom `log!` macro, ensuring `Error` log levels output directly to standard error stream.

Version 1.3.0
-------------
- Integrated Handshake (HNS) resolver daemon (hnsd) directly compiled with system unbound development dependencies.
- Implemented browser-managed hnsd subprocess lifecycle, dynamically starting and stopping the daemon with the browser.
- Added a DomainResolver trait to implement the Open-Closed Principle for future resolver plugins.
- Implemented SystemResolver fallback using rust standard library ToSocketAddrs resolving ICANN namespaces.
- Added a customizable, priority-ordered "Resolver Stack" configuration UI tab under juanita://config with interactive reordering controls.
